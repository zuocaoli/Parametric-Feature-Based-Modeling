# 几何引擎课程采用独立周框架副本

确认于 2026-10-29，开始实现六个月课程框架时。

- 每周复制一份完整框架，不共享课程源码或构建产物；共同引用分类下 `occt/` 第三方安装。
- 工具链固定 Clang + CMake + Ninja + clangd；项目允许 C++20 及以上，本模板选 C++23、`import std;`，不提供 C++20 兼容实现。
- Qt Widgets 承载 OCCT 视窗；同一实验支持参数面板与无窗口命令行。
- 提供运行、阶段模型、检查、输出和测试底座；建模算法直接写在每周实验中。
- 先交付框架设计与长方体示例模板，不提前铺设全部 24 周课程。

详细设计见 `几何引擎/plan/课程代码框架设计.md`；独立模板见 `几何引擎/template/week-template/`。
