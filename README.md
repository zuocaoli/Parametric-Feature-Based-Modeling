# 参数化几何建模平台核心模块学习

本项目用于学习 **参数化几何建模平台涉及到的核心模块**，以参数化矩形为贯穿案例，理解各模块的设计、运行机制与协作方式。

## 模块与课程

| 分类 | 学习内容 | 当前课程 |
|---|---|---|
| [文档与属性系统](文档与属性系统/README.md) | 对象与属性、文档、编辑器与验证 | 4 个月，16 周 |
| [表达式引擎与依赖图](表达式引擎与依赖图/README.md) | 解析、求值、依赖管理与增量重算 | 2 个月，8 周 |
| [单位系统](单位系统/README.md) | FreeCAD量纲、单位制与App协作设计 | 1 个月，4 周已按FreeCAD设计思想实现 |
| [几何引擎](几何引擎/README.md) | 几何表示、运算与拓扑关系 | 第 1 月 4 周已实现，后续按 6 个月规划推进 |
| [二维约束求解](二维约束求解/README.md) | 草图关系、自由度与约束求解 | 预留 |

课程目标与学习成果见各分类和各周 README；单位系统的详细问题、讲解与练习见[课程安排](单位系统/课程安排.md)及各周《课程讲义》。

## 学习顺序

文档与属性系统第 1 月 → 表达式引擎与依赖图第 1–2 月 → 文档与属性系统第 2–4 月 → 单位系统第 1 月 → 几何引擎第 1 月（后续月份按规划推进）。

课程目录为 `<分类>/monthNN/weekYY/`，每个分类的月份独立从 month01 编号。

## 独立构建与运行

含代码的每周课程使用 **Clang + CMake + clangd**，在该周目录执行：

```bash
./run.sh
```

或依次执行 `cmake --preset default`、`cmake --build --preset default`、`./build/demo`。每周可单独作为 IDE 文件夹打开；依赖和测试命令见本周 `tools/README.md`。QML 课程另需 Qt6；单位系统为标准库控制台课程，采用八维量纲和毫米／度内部值。
