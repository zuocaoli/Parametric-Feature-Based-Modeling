# CAD 学习课程

七个月、28 门独立课程、140 个问题；每周 README 集中回答五题。贯穿案例是参数化矩形：从合法尺寸与属性开始，逐步加入公式、依赖重算、撤销保存、QML 界面、交付验证和单位系统设计。

## 学习路线

| 月份 | 承接的成果 | 本月新增能力与阶段成果 | 下一月要解决的局限 |
|---|---|---|---|
| [第一月](month01/week01/README.md) | 一个保存尺寸的普通矩形类 | 统一属性、校验、通知和稳定身份；能管理、查看、修改多个对象 | width 与 length 的关系仍由调用者维护 |
| [第二月](month02/week01/README.md) | 已有统一属性读写入口 | 解析并绑定公式、手动计算、保存恢复；area 从按需读取转为公式写回的存储值 | 调用者仍需决定计算顺序和时机 |
| [第三月](month03/week01/README.md) | AST、求值与公式绑定 | 提取依赖、拓扑排序、增量重算与错误恢复；修改 length 后自动更新 width/area | 已提交编辑缺少整体撤销与文档事务 |
| [第四月](month04/week01/README.md) | 自动重算和稳定对象 ID | 命令、组合事务、历史与多对象保存；失败编辑保护和身份恢复 | 操作入口仍为控制台与核心接口 |
| [第五月](month05/week01/README.md) | 可撤销、可保存的参数化文档 | Qt 适配、二维显示、属性/公式编辑和拖动；可交互的小型编辑器 | 草稿、未保存判断与完整流程需要更系统的验证 |
| [第六月](month06/week01/README.md) | 完整 QML 编辑器 | 状态一致性、差分验证、性能测量和统一操作接口；可复现的交付案例 | 单位仍是标签，表达式与文档尚无完整的量纲约束 |
| [第七月](month07/week01/README.md) | 毫米矩形、表达式、重算和事务 | 工程量与换算、输入显示、带单位公式、文档持久化与交换的协作设计 | 进一步处理几何与约束求解中的尺度、残差和容差 |

各月下面列出原题目，点击周次进入课程。先读本周目标和五题答案，再运行示例完成独立练习。每周目录可单独在 IDE 中打开。

## 运行课程

第一至六月在任一周目录执行 `./run.sh`，脚本构建本周、更新代码跳转信息并运行程序。第五、六月的 QML 界面需要 Qt6；依赖版本、测试命令及 IDE 设置见[工具说明](docs/tooling.md)。第七月是设计与机制课程，通过各周 README 的执行轨迹和练习学习，无需编译；工具的 `all` 仍覆盖前六个月的可运行课程。
