# 参数化几何建模平台核心模块学习

本项目用于学习 **参数化几何建模平台涉及到的核心模块**，以参数化矩形为贯穿案例，理解各模块的设计、运行机制与协作方式。

## 模块与课程

| 分类 | 学习内容 | 当前课程 |
|---|---|---|
| [文档与属性系统](文档与属性系统/README.md) | 对象与属性、文档、编辑器与验证 | 4 个月，16 周 |
| [表达式引擎与依赖图](表达式引擎与依赖图/README.md) | 解析、求值、依赖管理与增量重算 | 2 个月，8 周 |
| [单位系统](单位系统/README.md) | 工程量、单位换算及与表达式、文档的协作 | 1 个月，4 周讲义 |
| [几何引擎](几何引擎/README.md) | 几何表示、运算与拓扑关系 | 预留 |
| [二维约束求解](二维约束求解/README.md) | 草图关系、自由度与约束求解 | 预留 |
| [三维约束求解](三维约束求解/README.md) | 空间关系、自由度与约束求解 | 预留 |
| [事务系统](事务系统/README.md) | 命令、事务、撤销与重做 | 预留 |

详细目标、逐周问题和阶段成果见各分类 README；每周 README 集中回答五题，并给出独立练习和验收标准。

## 学习顺序

文档与属性系统第 1 月 → 表达式引擎与依赖图第 1–2 月 → 文档与属性系统第 2–4 月 → 单位系统第 1 月。

课程目录为 `<分类>/monthNN/weekYY/`，每个分类的月份独立从 month01 编号。

## 独立构建与运行

含代码的每周课程使用 **Clang + CMake + clangd**，在该周目录执行：

```bash
./run.sh
```

或依次执行 `cmake --preset default`、`cmake --build --preset default`、`./build/demo`。每周可单独作为 IDE 文件夹打开；依赖和测试命令见本周 `tools/README.md`。QML 课程另需 Qt6，单位系统讲义无需构建。
