# 第七个月第 3 周：单位与表达式、依赖重算

## 本周训练

- **承接与前置**：[上一周](../week02/README.md)已把输入转换成确定的工程量；复习第二月 AST、第三月依赖图和第四月事务。
- **目标**：跟踪带量纲的值如何穿过公式、目标属性和重算链；区分类型错误与合法公式运行失败。
- **独立练习**：初始 `length = 1000 mm`，绑定 `width = length / 2 + 10 mm`、`area = length * width`；将 length 改为 `2 m`，再尝试把 width 的公式改成 `length + 10 kg`。
- **验收**：初始 width/area 为 `510 mm / 510000 mm²`；修改后为 `1010 mm / 2020000 mm²`；非法公式被拒绝，正式公式、依赖边、历史和结果均保留。

本周独立推演所需初始状态已在上面给出，无需编译。SI＋弧度是规范单位，length/width 为正长度，area 为面积；函数和带单位 AST 是拟议扩展，现有第六月程序尚未实现它们。

## 131. 表达式 AST 如何表示带单位常量和带类型属性引用？

现有 AST 的 Number 只保存 `double`，Variable 在求值时取属性。扩展后数字节点区分普通比例常量和数量常量，变量绑定到稳定的 `ObjectId + PropertyKey`，并取得目标属性的 `QuantitySpec`。

数量字面量在绑定阶段完成单位查找和规范化；节点保存规范值、类型、原文范围及单位定义版本。原文用于编辑和诊断，求值无需每次重新解析 `mm`。

```text
width = length / 2 + 10 mm

Add [Length]
  Divide [Length]
    PropertyRef(object_id, "length") [Length]
    Number(2) [Ratio]
  QuantityLiteral(0.01) [Length，规范单位 m]
```

属性引用从元数据获得类型，即使属性此刻计算失败，也可以完成公式的类型检查；实际求值仍需检查属性当前状态。源文本中的名字和单位符号不能直接充当持久身份。

接口可按“`parse → bind/type_check → evaluate → validate_target`”组织，返回 `std::expected<..., Error>`。Resolver 从返回裸数升级为返回值、类型及可用状态，避免丢失 Failed/Blocked 信息。

## 132. 求值器如何计算工程量，并保证结果能赋给目标属性？

求值器按树结构调用单位核心的加减乘除，不自行实现第二套换算规则。普通数值统一作为无量纲量参与计算；有单位属性读取为 Quantity。整数是否转换为比例需明确，超出浮点精确整数范围时应拒绝或使用专门策略；布尔值和字符串不隐式转成数字。

| AST 步骤 | 计算 | 类型检查 |
|---|---|---|
| 读取 length | `1 m` | 属性状态必须可用 |
| 除以 2 | `0.5 m` | 长度÷比例，保留长度 |
| 加 `10 mm` | `0.5 m + 0.01 m = 0.51 m` | 两侧均为长度 |
| 写入 width | `0.51 m` | 匹配 Length，有限且大于零 |
| 计算 area | `1 m × 0.51 m = 0.51 m²` | 匹配 Area |

类型正确不等于值合法：`width = -1 mm` 是长度，但违反正尺寸约束；`width = length * length` 得到面积，必须在目标赋值前拒绝。检查顺序为量纲、工程类型、绝对量/差量类别、有限性和业务取值范围。

所有公式写回仍经过属性的统一校验入口。单位系统提供规则，表达式引擎不获得绕过属性约束的权限。不同单位输入先规范化，再比较是否变化；不得比较显示字符串来决定是否通知。

## 133. 函数、幂运算和无量纲值如何参与量纲检查？

函数注册表为每个函数声明参数类型和返回类型推导规则；检查可以在绑定时完成，数值定义域则在求值时检查。

| 函数/运算 | 本课程规则 |
|---|---|
| `sin(angle)`、`cos(angle)` | 接收 Angle，规范弧度调用数学函数，返回 Ratio |
| `asin(ratio)` | 接收 Ratio，检查范围 `[-1,1]`，返回 Angle |
| `atan2(y, x)` | 参数量纲及语义兼容，结果为 Angle；`(0,0)` 按本课规则报错 |
| `sqrt(area)` | 非负值且各量纲指数可被 2 整除；面积结果为长度 |
| `pow(quantity, integer)` | 指数为编译/绑定时可确定的整数，量纲指数乘以该整数 |
| `exp(ratio)`、`log(ratio)` | 参数必须是普通比例；log 另要求大于零 |
| `min(a, b)` | 两项类型兼容，返回同类型值 |

整数指数模型不支持 `sqrt(1 m)`，也不支持让带量纲底数的指数随属性数值动态改变；这些需求需要扩展类型规则。无量纲底数的非整数幂可在数值定义域内单独支持。

特殊工程语义不会因量纲为零而自动消失：`log(30 deg)` 应拒绝。角度转为普通弧度数值必须经显式边界操作；能量/力矩等同量纲类型则由领域函数确认。新函数必须同时提供类型规则、数值实现和错误范围，不能只接入一个 `double → double` 回调。

## 134. 单位系统如何参与依赖图、增量重算和缓存失效？

依赖图仍只负责属性之间的关系。从绑定后的 AST 提取 PropertyRef；`10 mm` 是常量，`mm` 不成为属性依赖节点。

```text
length → width → area
   └──────────→ area
```

修改 length 后，重算器收集受影响的 width/area，按拓扑顺序各计算一次。area 必须读到本轮更新后的 width；重算写回通知不能再次启动同一计算链。

| 变化 | 需要处理什么 |
|---|---|
| 属性规范数值变化 | 标记下游、增量求值、发布最终状态 |
| 公式文本或属性引用映射变化 | 重新解析/绑定、检查类型和循环、更新依赖边 |
| 属性类型变化 | 重新检查受影响公式；本课程将属性类型固定，避免隐式变更 |
| 显示单位或显示精度变化 | 刷新格式缓存和标签，不标记模型数值为脏 |
| 默认输入单位变化 | 影响后续编辑，不重新解释既有 AST |
| 新增单位定义版本 | 新绑定使用新版本；既有绑定保持原版本 |

AST/类型缓存的身份包括公式文本、变量绑定、属性模式版本、单位定义版本和表达式语言版本，不能只有文本。单位定义只读且版本化后，纯数值编辑可以复用原 AST；显示缓存另加显示策略版本。

若业务确实要替换已有公式所引用的单位定义，应作为显式文档迁移重新绑定并重算受影响公式。不能让全局注册表修改绕过文档事务。

## 135. 单位错误、计算失败和恢复如何与事务协作？

绑定 `width = length + 10 kg` 时，元数据足以发现类型错误，命令在候选模型中失败，正式模型、旧公式、旧依赖边和历史均不变。错误指向不兼容的操作数，并报告期望/实际类型。

对于已经合法绑定的 `width = length / ratio`，ratio 是可取零的比例属性。把 ratio 改为零是合法输入，但执行时除零；沿用前几个月的语义：保留这次输入和撤销记录，width 标为 Failed，area 标为 Blocked。可以保留旧几何作带警告的预览，但下游不能把旧数值当成当前有效结果。

新建或替换公式时，确定的语法、引用、循环、类型和常量取值错误拒绝提交；合法绑定中的运行时失败则随候选文档提交为明确状态。若某公式的数值依赖当时不可用，可保持合法绑定并进入 Blocked，待前置恢复。

修复 ratio 或撤销到非零值后，按相同拓扑顺序重算，width/area 恢复 Valid。不相关分支继续计算。事务完成后发送一次包含最终值、状态和诊断的事件，UI 不观察到半更新的属性组合。
