# 子任务 1：实现矩形类与示例

状态：已完成。

- `001/main.cpp` 定义 Rectangle：公开的 double 长度 length 和宽度 width；构造函数初始化尺寸；`double area() const` 返回长度乘宽度。
- main 创建两个独立的只读矩形，尺寸分别为 5 × 3 和 2.5 × 4，并打印尺寸和面积。
- `001/.gitignore` 忽略 `/build/`，可执行文件将放在此目录。
- 后续文档使用 C++20 与标准库；本地编译器为 GCC 16.2.1。编译运行验证留给子任务 3。
- 预期输出为 `length=5, width=3, area=15` 和 `length=2.5, width=4, area=10`，各占一行。
- 设计取舍：面积按需计算，避免重复状态，每次访问进行一次乘法。公开尺寸便于观察对象数据，当前尚无合法性保证，后续练习再处理。
