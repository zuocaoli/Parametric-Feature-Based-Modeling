# 二维约束求解

以参数化矩形为贯穿案例，学习独立二维几何约束求解器的表示、数值求解、诊断和交互。课程共 **3 个月、12 周，每周一个功能点**；十二周均提供独立源码、五题讲解、练习与 CTest。

工具链为 **CMake + Ninja + Clang，C++23、具名模块和 `import std;`**。Eigen 是唯一数学依赖；Qt Widgets 提供最小验证画布。每周可单独作为 IDE 文件夹打开，不依赖其他周源码、构建产物或几何引擎。

## 逐周问题与学习边界

### month01/week01：几何元素与参数管理

用稳定 ID 管理点、线段、圆和圆弧，并建立连续参数向量。

1. 几何实体与自由参数有什么区别？
2. 线段为什么复用端点，而不再保存一份坐标？
3. 圆弧的圆心、半径和端点怎样共同表示形状？
4. 实体 ID 怎样映射到参数向量位置？
5. C++ 模块怎样划分公开接口与内部实现？

**成果**：model 测试验证共享参数、圆弧依赖、稳定 ID 以及非法 ID、非有限坐标和负半径的拒绝。画布显示矩形；本周不求解。

### month01/week02：约束残差构建

将 11 类约束转换为带来源和依赖信息的残差。

1. 几何关系怎样写成 F(x)=0？
2. 一条约束为什么可能产生多个方程？
3. 距离、角度和相切需要明确哪些方向或分支？
4. 圆弧端点在圆上的关系由谁维护？
5. 不同量纲的残差怎样比较和缩放？

**成果**：residual 测试覆盖 11 类关系、点线和点圆关联、两种圆圆相切、圆弧内部行与用户约束 ID 映射。

### month01/week03：数值 Jacobian

使用中心差分组装 Jacobian，验证步长与尺度的影响。

1. Jacobian 每一行、每一列分别表示什么？
2. 中心差分怎样近似偏导数？
3. 步长过大或过小分别产生什么误差？
4. 参数尺度与残差尺度怎样影响数值结果？
5. 怎样用已知导数验证 Jacobian？

**成果**：jacobian 测试将抽查导数误差控制在 1e−5 内，覆盖步长非法输入与角度跨 ±π 时的周期差分。

### month01/week04：Newton 求解

实现具有回溯线搜索和失败回退的全量 Newton 求解。

1. 为什么能用线性方程近似非线性约束？
2. 如何计算 Newton 更新量？
3. 非方阵或秩不足时为什么不能直接使用普通 LU？
4. 回溯线搜索怎样避免残差增大？
5. 怎样区分收敛、停滞和迭代超限？

**成果**：solver 验证矩形在 10 次内收敛、11 类关系从扰动初值可解及热启动；pathology 验证退化线、同心相切圆、非法选项和空系统。

**阶段衔接**：求解成功还不能说明剩余多少自由度，下一月补上系统分析。

### month02/week01：结构自由度分析

用方程—参数二部图最大匹配估计结构自由度。

1. 方程与参数怎样组成二部图？
2. 静态依赖关系为何优于某次 Jacobian 的偶然非零值？
3. 增广路径怎样增加匹配数量？
4. 未匹配参数能说明什么？
5. 结构自由度为什么不一定等于实际自由度？

**成果**：structure 测试验证三种构型的结构自由度分别为 0、1、0。本周 SolveReport 的 dof 尚为 −1，只有 structuralDof 可用。

### month02/week02：数值自由度分析

基于 Jacobian 数值秩报告局部自由度和参与运动的参数。

1. 参数数 − rank(J) 为什么表示局部自由度？
2. 数值秩与结构秩有什么区别？
3. 秩判定阈值怎样受到缩放影响？
4. 零空间怎样描述允许的微小运动？
5. 奇异位置为何不能直接代表一般构型？

**成果**：rank 测试验证完整矩形 dof=0、删宽度 dof=1，以及重复水平约束时 structuralDof=0 而 dof=1；返回可动参数索引。

### month02/week03：冗余约束定位

把相容系统中的相关方程定位到用户约束 ID。

1. 方程数量多为什么不一定意味着冲突？
2. 行相关与约束冗余有什么关系？
3. 多方程约束怎样作为整体判断？
4. 存在多个等价冗余集合时怎样稳定输出？
5. 为什么还要检查残差相容性？

**成果**：redundancy 测试精确返回新增宽度 ID，验证固定约束两行归一 ID，并验证 Redundant 状态下 dof 仍能为 1。

### month02/week04：冲突约束定位

定位可确证的同对象尺寸矛盾，并保留一般非收敛的失败语义。

1. 残差不收敛为什么不能直接证明无解？
2. 冗余与矛盾在方程中分别表现为什么？
3. 怎样通过约束组剔除和重解缩小冲突集合？
4. 局部极小冲突集合与最小冲突集合有什么区别？
5. 无法可靠判定时报告应该表达什么？

**成果**：conflict 测试返回两条宽度 ID，验证反向点距规范化、固定约束冲突、几何回退与删除后的恢复。

**阶段衔接**：利用已经具备诊断和回退的求解器进行尺寸驱动。

### month03/week01：尺寸驱动更新

通过修改尺寸目标值驱动模型连续更新。

1. 尺寸目标值与几何参数有什么区别？
2. 修改尺寸后为什么沿用上次成功构型？
3. 失败更新怎样避免污染当前几何？
4. 连续小幅修改为何通常比大幅跳变稳定？
5. 相切和角度分支怎样保持明确？

**成果**：dimensions 测试覆盖连续尺寸更新、非法值拒绝、失败时几何保持，以及相切圆的小步半径变化。Qt 面板从本周提供宽度编辑。

### month03/week02：带圆角矩形求解

用已有元素和约束构建完整圆角矩形，验证全约束与诊断。

1. 圆角矩形需要哪些实体和独立尺寸？
2. 直线与圆弧怎样共享连接端点？
3. 已知连接点时怎样表达切向连续？
4. 怎样避免重复施加隐含关系导致冗余？
5. 怎样证明基准模型已经全约束？

**成果**：rounded 测试验证 28 参数／28 行、10 次内收敛、dof=0、无冗余、尺寸连续更新；删除宽度后 dof=1。

### month03/week03：约束保持的点拖拽

在保持原约束的前提下，让被拖点逼近当前分支的局部可达位置。

1. 一个自由度为何通常不能满足任意两个坐标目标？
2. 硬约束与拖拽软目标分别承担什么职责？
3. 怎样利用约束 Jacobian 的零空间计算拖拽方向？
4. 拖拽步怎样经过原约束校正并提交？
5. 全约束、不可达目标和失败步骤怎样处理？

**成果**：drag 测试覆盖 20 步路径、不可达 y、全约束拒动、松手后保持、非法点与 NaN 目标回退。图形端仍为观察器，鼠标接入留到下一周。

完成最小 Qt Widgets 验证端，将已有能力接入交互。

1. 屏幕坐标怎样转换为模型坐标？
2. 点选取与拖拽生命周期怎样连接库 API？
3. 尺寸编辑怎样触发求解和状态刷新？
4. 如何显示可动参数、冗余和冲突来源？
5. 怎样验证交互结果与无头测试一致？

**成果**：ui 测试验证实际绘图、按钮、尺寸、诊断、鼠标拖拽与创建模式；生成 build/workbench.png 供人工检查。Release 测量包含诊断和拖拽的完整预算。

## 与 PRD 的明确化

[mini-2d-gcs-prd.md](mini-2d-gcs-prd.md) 保留原始需求草案，本轮不改写。课程按已经确认的方案采用以下语义：

- C++17 改为 C++23 模块；长度 mm，角度 rad，不引入单位系统依赖。
- 二部图只给出结构自由度，正式 `dof` 来自当前 Jacobian 数值秩；奇异构型下仅作一阶局部解释。
- 鼠标为软目标，原约束为硬约束；求解当前分支附近的局部可行改进，全约束时保持原位。
- 冲突确证限于同对象的不相容尺寸或固定坐标，返回两条来源 ID；一般非线性不收敛保守返回 `Failed`，不宣称已证明无解。
- 冗余在收敛构型按约束添加顺序识别，组合约束可能仅部分行相关，因此不自动删除整条约束。
- 热启动和显式相切分支支持局部连续，验收采用小幅连续路径，不承诺任意输入均无跳变。
- 图分解、增量求解、解析求导、稀疏求解、全局多解搜索、完整 CAD 编辑器均保持范围外。

## 核心接口与数值约定

`Sketch` 提供实体／约束创建、约束删除和参数查询；第 9 周增加尺寸目标更新。`Solver` 从第 4 周提供求解，第 11 周增加 `drag()` 与 `endDrag()`。构造时非法 ID、类型、非有限数值和非法半径抛标准异常；求解过程中的退化或数值失败返回结构化报告。

`SolveReport` 包含状态、局部和结构自由度、秩、可动参数、冗余／冲突 ID、迭代数、最终试算残差与原因。尚未引入的自由度字段为 −1。成功收敛分支按 Redundant → UnderConstrained → Success 显示，已确证冲突为 Conflicting，其他失败为 Failed；冗余与欠约束可以同时记录。

默认最多 50 次 Newton 更新；缩放残差容差 1e−8，几何退化阈值 1e−10 mm，中心差分步长 1e−7（随参数量级缩放），数值秩相对阈值 1e−8。特征长度 L 取至少 1 mm 的包围跨度／半径最大值，在单次求解内固定；长度残差除以 L，参数更新在 x/L 坐标中计算。每行还具有独立容差，取它与求解容差中较严者。故 L=100 mm 时 1e−8 的长度残差对应约 1e−6 mm。

`getEntityParams()` 的返回顺序为点 `[x,y]`、线段 `[ax,ay,bx,by]`、圆 `[cx,cy,r]`、圆弧 `[cx,cy,sx,sy,ex,ey,r]`。固定约束用 `addConstraint(Fixed,{point},x,y)` 提交两个坐标，圆圆相切通过 `TangencyBranch` 参数选择内外切。

点线关系针对支撑直线，点圆关系针对支撑圆；圆弧方向是显示元数据。Solver 实例保存上次成功解；修改目标后重解，失败保留几何而保留新目标，参数数量变化时以当前模型为初始构型。

## 最终验收对应

| PRD 用例 | 本课程测试 |
|---|---|
| AC-1 全约束圆角矩形 | `rounded`：28 参数／28 行、dof=0、规定扰动 10 次内收敛 |
