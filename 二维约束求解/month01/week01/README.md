# 第 1 月第 1 周：几何元素与参数管理

## 本周训练

- **承接与前置**：会使用 C++ 类、容器和基本三角函数；从参数化矩形进入草图表示。
- **唯一新增功能**：用稳定 ID 管理点、线段、圆和圆弧，并建立连续参数向量。
- **学习方式**：先推导本周必要公式，再阅读模块实现，最后改变输入并核对结果。

## 1. 几何实体与自由参数有什么区别？

实体表达点、线、圆等对象身份，参数表达可以改变的数值。点拥有 x、y，圆另拥有半径；共享同一个点实体时，也共享同一组坐标参数。

## 2. 线段为什么复用端点，而不再保存一份坐标？

线段只保存两个点 ID，本身不增加参数。两个线段引用相同点 ID 就已连接；两份坐标恰好相等的独立点仍需要重合约束。

## 3. 圆弧的圆心、半径和端点怎样共同表示形状？

圆弧引用圆心、起点和终点，并拥有半径参数与绘制方向。端点在圆上的两个内部方程从下一周开始维护；本周允许输入尚未满足这些关系的初始构型。

## 4. 实体 ID 怎样映射到参数向量位置？

实体保存其直接拥有的参数索引，parameterIndices() 递归汇总引用点的索引。ID 从 1 递增且实体不删除；参数连续编号，线段无需额外编号。

## 5. C++ 模块怎样划分公开接口与内部实现？

model.cppm 导出类型和声明，model.cpp 提供实现；lesson 模块构造本周示例。CMake 的 CXX_MODULES 文件集负责扫描依赖和构建 BMI，不手写模块编译顺序。

## 独立练习与验收

构建矩形、圆和圆弧，令线段和圆弧共享一个端点；通过 setParameters() 修改它的坐标，比较两种实体查询结果。

model 测试验证共享参数、圆弧依赖、稳定 ID 以及非法 ID、非有限坐标和负半径的拒绝。画布显示矩形；本周不求解。

实现入口：[src/model.cpp](src/model.cpp)；验证入口：[核心测试](tests/core_tests.cpp)。

```bash
cmake --preset default
cmake --build --preset default
ctest --preset default --no-tests=error
ctest --preset default -R "^(model)$" --no-tests=error
./build/console-demo --headless
./build/demo
```

依赖版本、Qt 可选配置、运行参数与 clangd 设置见 [tools/README.md](tools/README.md)。
