# 第 1 月第 2 周：约束残差构建

## 本周训练

- **承接与前置**：承接点、实体 ID 与连续参数向量。
- **唯一新增功能**：将 11 类约束转换为带来源和依赖信息的残差。
- **学习方式**：先推导本周必要公式，再阅读模块实现，最后改变输入并核对结果。

## 1. 几何关系怎样写成 F(x)=0？

例如水平线的残差为 (yB−yA)/L，点点距离为 (‖B−A‖−d)/L。L 为特征长度；零残差表示关系满足，不意味着全部参数都已经固定。

## 2. 一条约束为什么可能产生多个方程？

重合和固定分别约束 x、y，产生两行。每行保留同一约束 ID；圆弧的端点在圆上方程属于内部关系，以 intrinsicEntity 标识，约束 ID 为 0。

## 3. 距离、角度和相切需要明确哪些方向或分支？

点线距离与线圆相切保存初始有向侧别；角度以有向 atan2 表达并包裹到 ±π。圆圆相切使用显式内切／外切分支；点在直线上指支撑直线，不做线段范围限制。

## 4. 圆弧端点在圆上的关系由谁维护？

evaluate() 自动添加两条内部方程。直线与圆弧共享端点时，相切用该端点的半径向量与直线方向垂直来表达，避免只用圆心距造成连接点处的一阶秩退化。

## 5. 不同量纲的残差怎样比较和缩放？

长度残差除以 L，方向关系使用归一化点积或叉积，角度残差采用弧度。求解容差针对缩放后的无量纲残差；几何退化阈值按 mm 单独处理。

## 独立练习与验收

对 11 类约束各构造满足与违反的输入，记录残差；另比较内切、外切和圆弧连接点相切。
