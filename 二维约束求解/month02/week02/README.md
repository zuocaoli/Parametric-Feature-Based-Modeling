# 第 2 月第 2 周：数值自由度分析

## 本周训练

- **承接与前置**：承接结构匹配；补充秩、奇异值和零空间。
- **唯一新增功能**：基于 Jacobian 数值秩报告局部自由度和参与运动的参数。
- **学习方式**：先推导本周必要公式，再阅读模块实现，最后改变输入并核对结果。

## 1. 参数数 − rank(J) 为什么表示局部自由度？

满足线性化约束的微小运动满足 JΔ=0，其解空间维数为参数数减秩。这是当前构型的一阶局部结论，在奇异位置不能直接推广为全局可运动性。

## 2. 数值秩与结构秩有什么区别？

结构秩估计潜在独立关系，数值秩检查当前矩阵中实际独立的方向。重复水平约束虽然能够匹配另一个参数，却不会增加数值秩。

## 3. 秩判定阈值怎样受到缩放影响？

SVD 以相对最大奇异值的阈值判断秩，默认 1e−8。缩放不良会把很小但有效的方向误认为零，因此需要同时理解缩放和阈值。

## 4. 零空间怎样描述允许的微小运动？

SVD 的右奇异向量组成零空间基；每个基向量是一种允许的线性化运动。某参数在所有基向量中的分量均接近零时，才将其视为局部不动。

## 5. 奇异位置为何不能直接代表一般构型？

例如某些重合点的距离约束没有稳定方向，Jacobian 可能失秩。报告的是局部一阶分析，应配合附近构型与实际运动验证，不能声称已经证明机构自由度。
