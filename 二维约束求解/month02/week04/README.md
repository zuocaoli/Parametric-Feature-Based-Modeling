# 第 2 月第 4 周：冲突约束定位

## 本周训练

- **承接与前置**：承接冗余诊断、稳定 ID 与失败回退。
- **唯一新增功能**：定位可确证的同对象尺寸矛盾，并保留一般非收敛的失败语义。
- **学习方式**：先推导本周必要公式，再阅读模块实现，最后改变输入并核对结果。

## 1. 残差不收敛为什么不能直接证明无解？

局部方法也可能因初值、退化和线搜索停滞而失败。因此求解失败默认返回 Failed，只有存在明确矛盾证据时才返回 Conflicting。

## 2. 冗余与矛盾在方程中分别表现为什么？

相同对象要求相同距离时可同时满足；要求 100 与 120 时不可能同时满足。比较目标差与两行允许误差之和，可直接确证这类矛盾。

## 3. 怎样通过约束组剔除和重解缩小冲突集合？

一般方法是尝试删除组并重解，但局部求解失败并不构成无解证据。本课程先按类型和规范化对象分组，直接抽取目标不相容的两个 ID；删除任意一个后再重解作为恢复验证。

## 4. 局部极小冲突集合与最小冲突集合有什么区别？

极小指不能再删去成员而仍保留已证矛盾，最小指在所有冲突集合中成员数最少。本实现返回首先确证的矛盾尺寸对，不搜索所有冲突组合。

## 5. 无法可靠判定时报告应该表达什么？

返回 Failed 并给出迭代次数、试算残差与原因。当前确证范围包括相同对象的距离、半径、周期等价角度及固定坐标；不承诺识别任意非线性约束组合的无解。

## 独立练习与验收

在全约束矩形上添加反向引用的 120 mm 宽度，检查冲突对；删除它后重新求解，再添加矛盾固定坐标。

conflict 测试返回两条宽度 ID，验证反向点距规范化、固定约束冲突、几何回退与删除后的恢复。

实现入口：[src/diagnostics.cpp](src/diagnostics.cpp)；验证入口：[核心测试](tests/core_tests.cpp)。

```bash
cmake --preset default
cmake --build --preset default
ctest --preset default --no-tests=error
ctest --preset default -R "^(conflict)$" --no-tests=error
./build/console-demo --headless
./build/demo
```

依赖版本、Qt 可选配置、运行参数与 clangd 设置见 [tools/README.md](tools/README.md)。
