# 第 3 月第 2 周：带圆角矩形求解

## 本周训练

- **承接与前置**：承接尺寸驱动；不增加约束种类。
- **唯一新增功能**：用已有元素和约束构建完整圆角矩形，验证全约束与诊断。
- **学习方式**：先推导本周必要公式，再阅读模块实现，最后改变输入并核对结果。

## 1. 圆角矩形需要哪些实体和独立尺寸？

基准为宽 100、高 60、四角半径 10 mm。8 个边界连接点、4 个圆心与 4 个半径共 28 参数；四条直边复用连接点，不额外占参数。

## 2. 直线与圆弧怎样共享连接端点？

每个圆弧引用相邻直边的实际端点，无需再添加重合约束。圆弧中心是独立点，起终点在圆上的 8 条内部方程自动加入。

## 3. 已知连接点时怎样表达切向连续？

在共享连接点处约束半径向量与直边方向垂直，配合端点在圆上形成相切。相比仅约束圆心到支撑线距离，这种表达对端点的切向位置提供有效一阶信息。

## 4. 怎样避免重复施加隐含关系导致冗余？

使用 8 条相切、4 条半径、4 条水平／竖直、2 条宽高及锚点的 2 行，加内部 8 行，共 28 行。四个半径分别指定，不加入 P2 的等半径关系。

## 5. 怎样证明基准模型已经全约束？

收敛后检查全部残差、数值秩 28 与 dof=0，并验证重复尺寸和冲突尺寸。宽度通过左侧连接点到右侧支撑线的距离表达，高度通过底部连接点到顶部支撑线表达。

## 独立练习与验收

从每个参数最多约 0.3 mm 的扰动恢复基准，逐步增加宽度，再分别添加重复宽度、矛盾宽度及删除宽度。

rounded 测试验证 28 参数／28 行、10 次内收敛、dof=0、无冗余、尺寸连续更新；删除宽度后 dof=1。

实现入口：[src/lesson.cpp](src/lesson.cpp)；验证入口：[核心测试](tests/core_tests.cpp)。

```bash
cmake --preset default
cmake --build --preset default
ctest --preset default --no-tests=error
ctest --preset default -R "^(rounded)$" --no-tests=error
./build/console-demo --headless
./build/demo
```

依赖版本、Qt 可选配置、运行参数与 clangd 设置见 [tools/README.md](tools/README.md)。
