# 第 3 月第 3 周：约束保持的点拖拽

## 本周训练

- **承接与前置**：承接圆角矩形、Jacobian 零空间和最小二乘。
- **唯一新增功能**：在保持原约束的前提下，让被拖点逼近当前分支的局部可达位置。
- **学习方式**：先推导本周必要公式，再阅读模块实现，最后改变输入并核对结果。

## 1. 一个自由度为何通常不能满足任意两个坐标目标？

点可能只能沿一条轨迹运动，任意鼠标 x、y 不一定位于轨迹上。把两坐标同时作为硬约束会制造冲突，因此鼠标位置作为软目标处理。

## 2. 硬约束与拖拽软目标分别承担什么职责？

原有几何和尺寸关系必须满足；鼠标目标用于选择可行构型。全约束时返回当前构型并说明拖拽无效果，不删除尺寸以迎合鼠标。

## 3. 怎样利用约束 Jacobian 的零空间计算拖拽方向？

用 Δ=Nα 表达保持线性化约束的运动，抽取被拖点的两行形成小最小二乘问题。求 α 后得到全体参数的跟随方向。

## 4. 拖拽步怎样经过原约束校正并提交？

限制单步大小并回溯，使用 Newton 重新满足原硬约束，只接受点到目标距离下降的可行候选。每次成功拖拽保存构型；失败保留先前几何。

## 5. 全约束、不可达目标和失败步骤怎样处理？

全约束保持原位；不可达目标返回找到的局部可行改进，没有改进时附带原因。endDrag() 保存最终构型，无临时硬约束残留；不承诺全局最近点。

## 独立练习与验收

删除圆角矩形宽度，把右下连接点目标沿 x 递增并偏离其固定 y；观察 x 跟随、y 保持、全部硬约束满足。

drag 测试覆盖 20 步路径、不可达 y、全约束拒动、松手后保持、非法点与 NaN 目标回退。图形端仍为观察器，鼠标接入留到下一周。
