# 单位系统

## 核心目标

以 FreeCAD 的单位系统设计为参考，理解带单位的数据怎样完成输入、计算、显示和保存，并掌握单位系统与属性、表达式及参数化文档的协作方式。

## 学完后能够掌握

- 区分量纲、单位、工程量与显示文本，设计 Unit 和 Quantity 的职责边界。
- 实现量纲运算与单位换算，解释毫米、度等内部单位约定的影响。
- 解析带单位输入，通过单位制与格式规则显示同一个内部值。
- 让属性和表达式携带量纲，正确处理类型检查、取值约束与依赖重算。
- 协调应用偏好、文档配置和编辑上下文，使显示切换、撤销及保存加载保持一致。
