## 第一月：单位系统及其协作机制

四周完整讲义均含五题答案、独立练习和验收标准。案例为 length=`1000 mm`、width=`length/2 + 10 mm`、area=`length*width`；沿着输入、规范化、求值、重算、撤销和保存逐步推演。

本月接口、单位语法和 CAD_DOCUMENT 3 均为教学设计，尚未接入现有示例程序。月底能够解释显示切换为何不改变几何、类型错误为何拒绝提交、运行时失败如何恢复，以及保存和交换为何需要明确的单位契约；下一阶段进入几何和约束求解的尺度与容差。
