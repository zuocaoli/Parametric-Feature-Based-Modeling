# 第2周讲义：输入解析与数据驱动的单位制

## 本周训练

- **承接与前置**：[上周](../week01/README.md)已实现八维Unit和毫米／度Quantity，本周连接文本与显示。
- **目标**：分离数量解析、格式、单位制规格、单个schema、集合和统一服务入口。
- **独立练习**：解析25mm、2in、2 N/mm^2；为内部长度1000切换米／英寸显示，添加厘米教学规格，检查999/1000/−1000阈值。
- **验收**：内部25/50.8/2000；长度显示1m或39.3701in而内部仍1000，500000mm²显示5000cm²，边界为999mm/1m/−1m。

本周问题见[课程安排](../../课程安排.md#week02)。[schema.cppm](schema.cppm)提供QuantityFormat、UnitsSchemaSpec、UnitsSchema、UnitsSchemas和UnitsApi；[input.cpp](input.cpp)解析数量，不依赖属性或文档。

## 126. 数量解析器如何把数字、单位符号和复合单位转换为内部工程量？

依次识别有限数字、单位符号、单位乘除/整数幂，再调用核心换算。`2 N/mm^2`得到内部2000与压力量纲，除以Pa比例0.001显示为2000000Pa。支持科学计数法、大小写敏感符号、括号、µm与²/³；未知单位和指数越界返回原始UTF-8字节位置。

方括号按FreeCAD数量入口约定作为注释：`2 [N/mm^2]`得到无量纲2，方括号内容不参与数值计算。注释用等长空格掩盖，保留诊断和字面量绑定的位置；未闭合注释拒绝。教学数量入口只解析一个数值和单位表达式，不实现FreeCAD完整算术语法。

## 127. QuantityFormat如何控制精度和显示样式，为什么不能参与模型计算？

格式仅控制固定小数位、有效数字及可选三位分组；格式化只读Quantity，不能把舍入标签写回模型。显式单位覆盖也须先校验量纲。输入不接受分组逗号，机器保存格式不使用UI标签。

分数英寸、多单位长度和完整本地化属于专用格式分支，本课程保留设计说明而未实现；固定数字格式足以验证“同一内部值、不同显示”。精度、换算误差和几何容差是三个概念，不能共用一个epsilon。

## 128. UnitsSchemaSpec与换算规格表如何描述不同工程量的显示规则？

规格包含稳定ID、名称、基本输入长度单位，以及按Unit索引的规则行。每行保存threshold、unit_string、factor；普通显示值=`内部值/factor`。新增厘米教学制只需长度factor=10、面积factor=100的数据，不复制翻译算法。

[schemas的内置数据](schema.cpp)包含Internal、MeterDecimal、ImperialDecimal、Centimeter、AdaptiveLength。Internal是固定内部单位的教学子集，不宣称完整复刻FreeCAD同名自适应方案或全部内置数据。同量纲的Work/Moment在本教学表中共用规则；若需要不同业务名称的显示，应增加独立业务元数据。

## 129. UnitsSchema如何根据量纲类型、数值范围和规格表选择显示单位？

用工程量Unit选择规则组，以数值绝对值选择首个阈值满足行，threshold=0为末尾默认行；未知类型回退到Unit的内部单位字符串和factor=1。规则在加入时校验比例、阈值顺序、默认行及身份冲突。

AdaptiveLength用1000阈值，得到999mm、1m、−1m；按参照源码在阈值比较时略微收紧边界，避免恰在边界的数值误选上一行。这是显示策略，不是几何容差。负值只影响符号，不改变单位选择。

## 130. UnitsSchemas与UnitsApi如何管理单位制集合、选择状态和统一调用入口？

集合按ID或名称选择schema，选择失败保持原方案；ID不等于表中位置。UnitsApi拥有注册表和集合，统一提供parse、format和capture。教学实现使用显式服务实例，未复制进程级全局静态单例；应用装配在第四周继续。

`capture`根据schema基本长度、属性覆盖和输入/显示设置冻结InputContext。输入裸数按该上下文解释，数量入口无上下文的裸数仍无量纲。切换schema后新编辑采用新单位，旧草稿继续使用旧单位，文档generation变化拒绝旧草稿。

基本输入长度与显示单位可分别设置：basic_length为cm而显示mm时，普通裸数2表示20mm；开启输入跟随显示后才表示2mm。属性输入覆盖优先于两者。

## 执行与运行

```text
1000 mm -> 内部1000 Length
MeterDecimal    -> 1.0000 m
ImperialDecimal -> 39.3701 in
切换后内部仍1000
```

在本周目录执行：

```bash
./run.sh
./run.sh '2 N/mm^2'
./run.sh '2 [N/mm^2]'
cmake --preset default
cmake --build --preset default
ctest --preset default --no-tests=error
```

最后两个数量命令分别输出内部压力2000和无量纲2。[input_tests.cpp](input_tests.cpp)、[schema_tests.cpp](schema_tests.cpp)覆盖语法、绑定、冻结输入、规格扩展和格式不回写；同时保留本周独立的核心测试。工具链与原生clangd见[tools/README.md](tools/README.md)，参考依据见[FreeCAD校对](../../FreeCAD-Unit/README.md)。
