# 第4周：应用装配、文档配置与完整生命周期

## 核心目标

将单位服务接入应用和文档，贯通输入、显示、重算、事务与持久化，保证同一工程量在整个生命周期中含义一致。

## 学完后能够掌握

- 划分单位核心、应用服务和文档的职责，完成单位服务装配。
- 协调全局偏好、文档单位制、属性覆盖与一次编辑的单位上下文。
- 区分数值变化与显示变化，正确触发通知、依赖重算及撤销重做。
- 保存权威输入、公式绑定与单位配置，加载时校验并重建派生结果。
- 用参数化矩形验证完整流程，处理单位交换及失败操作时的文档保护。
