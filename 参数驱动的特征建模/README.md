# 参数驱动的特征建模

用 C++23 和 OCCT 实现参数驱动的特征重建。课程承接表达式绑定、依赖图、批次重算和失败恢复，以同一块矩形底板和切槽练习从数值参数到几何结果的完整流程。

| 周次 | 课程 | 学习成果 |
| --- | --- | --- |
| 01 | [从参数到拉伸实体](month01/week01/README.md) | 用有效公式值驱动几何内核，并检验实体尺寸与体积。 |
| 02 | [多个特征的重建顺序](month01/week02/README.md) | 让切槽使用同轮重建得到的新底板。 |
| 03 | [特征的增量重建](month01/week03/README.md) | 只执行受参数变化影响的特征，并复用有效几何。 |
| 04 | [重建失败与恢复](month01/week04/README.md) | 检查失败传播、安全读取、缓存与修复。 |
| 05 | [重建后的面引用](month02/week01/README.md) | 让槽口随被引用的拉伸终止面移动。 |
| 06 | [全量与增量重建验证](month02/week02/README.md) | 用全量重建对照几何结果、执行范围和失败恢复。 |

从任一周目录运行 `./run.sh`，再用 `ctest --preset default --no-tests=error` 验收。各周包含完整源码和构建配置，使用 CMake、Clang、Ninja 与本目录的 `occt/` 安装包。 [课程路线](plan.md)
