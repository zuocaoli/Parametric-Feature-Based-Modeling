# 第 1 周 · 从参数到拉伸实体

**承接** · 表达式课程已经能绑定公式并查询有效数值。
**目标** · 把公式结果传给几何内核，生成可测量的三维实体。

## 五个设计问题

1. **特征定义保存什么？** 拉伸特征保存稳定的 `FeatureId`、矩形轮廓和高度参数的 `PropertyKey`。修改输入时，仍使用原来的特征 ID 查询结果。
2. **公式值如何交给特征？** 模型将 `height` 绑定为 `2 * t`。改参时，表达式引擎先完成重算，特征再通过 `value()` 取得有效高度。
3. **矩形如何变成实体？** 几何层连接四个角点，构造闭合线框和平面，再用 `BRepPrimAPI_MakePrism` 沿 Z 方向拉伸。
4. **为什么还要检查几何条件？** 数值求值成功只说明公式得到了数。拉伸还要求有限的正高度、可构造的轮廓和有效的实体。
5. **如何确认重建正确？** 用 OCCT 测量包围盒和体积，同时检查重建报告里的特征 ID、状态和执行次数。

## 练习与验收

先运行 `./run.sh`。在 [scenarios.cpp](scenarios.cpp) 的 `single_extrusion()` 中确认 `t` 从 `10` 改为 `15 mm` 后，底板高度从 `20` 变为 `30 mm`，体积从 `120000` 变为 `180000 mm³`。沿 [feature_model.cpp](feature_model.cpp) 找到高度进入 `extrude()` 的调用点。

独立练习将第二次输入改为 `12 mm`，同步更新自己对高度和体积的预期。验收值为 `24 mm`、`144000 mm³`，重建报告中的特征 ID 保持一致。
