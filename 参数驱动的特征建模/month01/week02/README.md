# 第 2 周 · 多个特征的重建顺序

**承接** · 上周已能用公式值拉伸一个底板。
**目标** · 用底板实体和槽深作为切槽输入，按拓扑顺序全量重建。

## 五个设计问题

1. **切槽依赖什么？** 切槽定义保存被切除的底板特征 ID、固定平面上的矩形轮廓和槽深参数键。
2. **公式图和特征图各管什么？** 公式图安排属性求值，特征图安排几何生成。本周复用 `DependencyGraph` 的排序代码，用 `graph_key()` 将特征 ID 转成本图的节点键。
3. **如何表达先做底板？** 建立底板到切槽的有向边。全量重建选中所有特征，拓扑顺序保证先执行底板。
4. **如何让切槽读到新底板？** 底板成功后发布本轮实体。切槽执行时按 ID 取有效结果，再将底板和拉伸刀具体交给 OCCT 做布尔差。
5. **如何发现用错了旧实体？** 同时检查执行顺序和结果体积。即使日志顺序正确，错用旧底板也会导致体积仍为旧值。

## 练习与验收

运行 `./run.sh`，检查 `rebuild-order` 中底板和切槽各执行一次，底板在前。切槽轮廓从固定的 `z = 0` 平面沿 Z 轴正向拉伸，移除 `20 × 10 × 5 mm` 材料。底板高度从 `20` 增至 `30 mm` 后，切槽结果从 `119000` 变为 `179000 mm³`。

独立练习把 [scenarios.cpp](scenarios.cpp) 中的切槽轮廓宽度改为 `30 mm`，按面积乘槽深推导并更新本周切槽场景的预期体积。验收值为 `118500` 和 `178500 mm³`。
