# 第 3 周 · 特征的增量重建

**承接** · 上周已验证全量重建顺序。
**目标** · 根据实际输入变化选择要执行的特征，并复用有效的上游实体。

## 五个设计问题

1. **怎样判断几何输入变了？** 在数值重算完成后，读取每个特征消费的参数状态和有效值，与上轮快照比较。首次创建的特征也进入重建集合。
2. **为什么要沿特征图传播？** 底板尺寸改变会产生新实体。切槽即使槽深相同，也依赖这个新实体，因此要一起重建。
3. **只改槽深时如何复用底板？** 底板状态仍有效，且未被选择重建。切槽直接读取其缓存实体，布尔切除采用 OCCT 的非破坏模式。
4. **批量改参为何只执行一次？** `set_many()` 先统一提交参数并完成公式重算，模型再选择受影响的特征。拓扑排序只让每个选中节点出现一次。
5. **增量节省的是什么？** 本例扫描特征读取参数快照，节省的是几何内核操作。日志记录实际执行的 ID 和次数。

## 练习与验收

运行 `./run.sh`，查看 `incremental-rebuild`。深度从 `5` 改为 `8 mm` 时只有切槽执行，体积为 `118400 mm³`。同批将 `t` 改为 `15 mm`、槽深改为 `6 mm` 时，底板与切槽各执行一次，体积为 `178800 mm³`。重复同一批输入时，重建报告为空。

独立练习在 [scenarios.cpp](scenarios.cpp) 中增加一次只改槽深的编辑，从 `6` 改为 `7 mm`。验收时只有切槽执行，体积为 `178600 mm³`。
