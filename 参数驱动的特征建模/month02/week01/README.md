# 第 5 周 · 重建后的面引用

**承接** · 上周已建立能传播失败且可以恢复的特征重建链。
**目标** · 让槽口随底板顶面定位，识别丢失和歧义的引用。

## 五个设计问题

1. **为什么面序号无法稳定表达选面意图？** 序号取决于当前结果的拓扑遍历顺序，重建或几何操作可能改变结果。课程用特征 ID 与「拉伸终止面」描述来源和角色。
2. **如何获得这个角色对应的面？** 拉伸成功后，从 `BRepPrimAPI_MakePrism::LastShape()` 收集终止面候选，并把候选随本轮实体一起发布。
3. **切槽如何使用该面？** 用底板特征 ID 取得本轮几何，要求恰好解析出一个水平终止面。由该平面读取 Z 坐标，再沿负 Z 方向生成刀具体。
4. **找不到面或找到多个面怎么办？** 返回可区分的缺失或歧义诊断，切槽记录 `Failed`。例如，用切除结果作为拉伸终止面来源时，它没有这个角色。
5. **怎样确认槽口跟着顶面移动？** 体积只能确认移除了多少材料。还要分类槽中心靠近顶面的点、槽底下面的点，以及槽旁的点，验证空洞与材料位于预期位置。

## 练习与验收

运行 `./run.sh`，查看 `face-reference`。当底板高度从 `20` 变为 `30 mm` 时，槽口从 `z = 20` 移到 `z = 30 mm`，槽深保持 `5 mm`。其中 `(50, 30, 27.5)` 应位于空洞，`(50, 30, 12.5)` 应位于实体内部。运行零候选和多候选测试，确认两种情况都有明确诊断。

独立练习在 [scenarios.cpp](scenarios.cpp) 中改用 `CutSupport::FixedPlane` 并保留顶面验收。确认体积仍相同而顶面点分类失败，再恢复顶面引用。
