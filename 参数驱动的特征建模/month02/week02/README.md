# 第 6 周 · 全量与增量重建验证

**承接** · 上周已能在每轮重建时解析底板的终止面。
**目标** · 用全量重建与解析计算共同校验增量重建，覆盖无关分支与失败恢复。

## 五个设计问题

1. **如何做可重复的对照？** 创建两个定义相同的模型，分别用 `RebuildMode::Incremental` 与 `RebuildMode::Full` 提交同一组修改。
2. **两种模式应共享什么？** 两者把选中的特征按同一种拓扑顺序执行，使用相同的参数读取、几何操作和发布规则。全量选择所有特征，增量选择受影响的特征。
3. **几何如何比较？** 对照包围盒、体积和顶面槽口的点分类。再用 `6000 * height - 200 * depth` 检查凹槽高度小于底板高度时的解析体积。
4. **如何验证局部性？** 记录两种模式实际执行的节点。全量每次尝试执行独立拉伸，增量在只编辑底板或切槽时复用其结果。
5. **失败场景应比较什么？** 比较失败节点、下游状态、是否能读取当前结果、缓存是否保留，以及修正输入后能否重新得到一致的实体。

## 练习与验收

运行 `./run.sh`，查看 `full-comparison`。分别修改底板高度、仅修改槽深、批量修改两项，再将 `t` 设为 `0` 后恢复。两种模式得到相同的有效几何和失败状态，独立实体在增量路径中始终被复用。

独立练习在 [scenarios.cpp](scenarios.cpp) 的对照场景中新增一轮 `t = 18 mm`、`depth = 9 mm`。验收结果为底板高度 `36 mm`、切槽体积 `214200 mm³`，两种模式的槽口都位于 `z = 36 mm`。
