## 第一月：表达式引擎基础

目标：自己实现词法分析、AST、递归下降解析与求值，将公式绑定到属性，手动计算并通过统一接口写回，保存后重新加载数值与公式。

| 周次 | 任务 | 需要解决的问题 |
|---|---|---|

| | 24 | 如何记录 Token 的位置，报告非法字符或数字？ |
| | 25 | 如何用正常、空白和错误输入验证 Lexer？ |
| [第 2 周：语法分析](month01/week02/README.md) | 26 | 为什么 Token 序列还不足以表达计算结构？AST 应有哪些节点？ |
| | 27 | 如何用递归下降解析体现乘除优先于加减？ |
| | 28 | 如何保证同级运算按左结合解析？ |
| | 29 | 如何处理括号与一元正负号？ |
| | 30 | 如何发现缺少操作数、括号不匹配和多余 Token？ |

| | 35 | 如何连接词法分析、语法分析与求值，并验证结果？ |
| [第 4 周：绑定与整合](month01/week04/README.md) | 36 | 如何分别保存属性的公式文本与最近一次成功计算的数值？ |

第一月代码使用 C++23 命名模块与 `import std;`，只依赖标准库，每周 README 说明设计取舍、源码位置及预期结果。前三周依次展示 Token、AST 和数值求值，具体输入方式见各周 README；第四周展示两轮矩形计算、错误保留与真实文件保存恢复。暂不加入单位运算、函数、跨对象引用或自动重算。

第四周演示得到 `width=50, area=5000`，修改 length 并手动重算后得到 `width=100, area=20000`；快照写入 `表达式引擎与依赖图/month01/week04/build/rectangle.txt`。

## 第二月：依赖图与增量重算

目标：从 AST 提取属性依赖，按拓扑顺序仅重算受影响公式，支持显式批次、循环拒绝、跨对象删除失效和错误修复。

|---|---|---|

|  | 43 | 如何用对象 ID 和属性键唯一标识属性？ |
|  | 44 | 如何用有向边表达属性间的依赖？ |
|  | 45 | 如何同时查询前置依赖和下游使用者？ |
| [第 2 周：确定计算顺序](month02/week02/README.md) | 46 | 为什么按属性创建顺序计算可能得到错误结果？ |
|  | 47 | 如何通过拓扑排序得到合法计算顺序？ |
|  | 48 | 多条路径汇聚时，如何让目标在前置更新完成后只计算一次？ |
|  | 49 | 如何识别公式直接引用自身？ |
|  | 50 | 如何检测循环依赖，并报告具体的闭合路径？ |

| [第 4 周：维护与错误恢复](month02/week04/README.md) | 56 | 公式替换或解除时，如何维护依赖边？ |

四周独立实现，前两月课程保持原样。第三周先停止失败轮次，第四周提供有效状态和分支隔离；只有协调操作结束后，派生数值才完成重算。

第四周输出矩形从 `50/5000` 更新为 `100/20000`，并报告 Failed、Blocked、MissingReference 与恢复后的 Valid 状态及实际执行次数。
